# Reference document sources and redistribution status

The README asks contributors to review redistribution rights before adding new
reference material. This is that review for the current `reference_documents/`
corpus (33 files), based on the copyright/license notices found in each
document's own text.

## Flagged — copyrighted by a private or non-federal body, kept as a known risk

These six are retained in the corpus by a deliberate decision, not an oversight.
If this project's usage model changes (e.g. redistributing the corpus itself,
rather than using it for retrieval within this app), re-review these first.

| File | Publisher | Why it's flagged |
|---|---|---|
| `ashi_home_inspection_standards.pdf` | American Society of Home Inspectors | "© Copyright 2026 ASHI, Inc. All rights reserved." The document's own license grants royalty-free reuse only to governments and educational institutions in the US/Canada — this project is neither. |
| `naic_homeowners_insurance_guide.pdf` | National Association of Insurance Commissioners | "© 1993, 2006, 2010 NAIC. All rights reserved." NAIC is a standards body, not a government agency. |
| `fannie_mae_appraisal_report_1004.pdf` | Fannie Mae / Freddie Mac | Copyrighted standard form. This copy is watermarked "Form provided courtesy of www.e-appraise.com" — it's already a third-party redistribution, not sourced from Fannie Mae/Freddie Mac directly. |
| `nar_buyer_agreements_explainer.html` | National Association of Realtors | NAR is a private trade association; its consumer guides and the REALTOR® mark are proprietary. |
| `nar_commissions_explainer.html` | National Association of Realtors | Same as above. |
| `tsahc_downpayment_assistance.html` | Texas State Affordable Housing Corporation | TSAHC is a state-chartered nonprofit, not a state government agency — its site content doesn't carry the public-domain/public-use status that CalHFA's or TREC's does. |

## Method

Each PDF/HTML file's extracted text (`reference_documents_txt/`) was searched
for copyright notices, license grants, and restriction language. Absence of a
notice was not treated as evidence of public-domain status; classification
above is based on an explicit notice found in the text, or on the publisher
being a US federal or state government body.
